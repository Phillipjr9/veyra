# Asset marks

21 self-hosted marks from cryptocurrency-icons 0.18.1 (https://github.com/spothq/cryptocurrency-icons), CC0; license included. NEAR, APT and ARB are local vector interpretations of their network marks. Project names and marks belong to their respective owners. No affiliation is implied.

Every supported asset in shared/catalog.ts must have one distinct lowercase SVG here. Never substitute a generic coin for a supported asset.
